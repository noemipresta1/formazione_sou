# Questo script mostra gli exit/exit status.

* Stampa *hello*
* Stampa $? (il codice di ritorno darà 0 perché il comando eseguito ha avuto successo).
<br>

* lskdf (comando che non esiste)
* Stampa $? (codice di ritorno diverso da 0, comando fallito). 
<br>


*  Stampa riga vuota
*  exit 113 (Indica al sistema che lo script ha restituito il codice 113).

<br> 


\# Per verificare il codice di ritorno scrivere *"echo $?"* dopo che lo script è terminato.

 \# Secondo la convenzione, un' *uscita 0* indica successo.
 
  \# Mentre un' *uscita diversa da 0* corrisponde a una condizione di errore o anomalia.
