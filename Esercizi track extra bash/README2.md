# Report esercizi - Noemi
## In questa cartella ho raccolto alcuni esercizi della track extra Bash (n.5-9)

***Esercizio 5:** Scrivere uno script che accetti un argomento numerico e stampi la sequenze di numeri da 1 a quel numero con l'indicazione se è pari o dispari. Controllare il corretto numero di argomenti passati allo script e che l'argomento sia di tipo numerico, in caso contrario generare una condizione di errore.* 

***Esercizio 6:** Scrivere un programma AWK che prende in input un file .csv e stampa il terzo campo solo se viene matchata la stringa "banana".* 

***Esercizio 7:** Utilizzare il comando egrep per risolvere i seguenti esercizi (dando esempi di possibili input):*

-Matchare sequenze alfabetiche di almeno un carattere, sia maiuscole che minuscole

-Togliere tutte le righe di commento di uno script Bash matchando le righe che iniziano con '#'

-Matchare in un file le righe che contengono sequenze di 'a' ripetute da 3 a 6 volte

-Matchare in un file tutte le righe che contengono una delle seguenti parole: apple, pear, orange* 

***Esercizio 8:** Scrivere una o piu' espressioni regolari (in OR) che matchino tutti i possibili indirizzi ipv4 in decimal dottet notation.* 

***Esercizio 9:** Supponiamo di avere 2 VM sul vostro laptop che riescano a "vedersi" lato rete. Scrivere uno script Bash che si comporti come un "port scanner" per capire quali porte TCP sono in ascolto sull'altra VM. E' richiesto di farlo tramite un ciclo che invochi il comando nc (NetCat) e non usando l'apposita feature di tale comando. E' inoltre gradita la customizzazione dell'ip/host target e del range di porte da linea di comando tramite argomenti e relativa sanificazione dell'input.*
